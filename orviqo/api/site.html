How it works

Small businesses in Nigeria run on informal credit, and the records live in notebooks and memory. Orviqo works where owners already are: one WhatsApp chat, no app to install, no forms.

Record

Plain messages become structured debts: who, how much, what for, when it's due. Follow-ups update the right debt instead of creating a duplicate.

Reconcile

"Chidi paid 50k" settles or reduces the debt and shows the running balance. If he has two open debts, it asks which one.

Remind and chase

A daily digest of overdue debts for the owner, and, with the owner's say-so, a polite WhatsApp reminder to the debtor that honors STOP.

Built to ask, not guess

The interesting part isn't the model. It's knowing when not to act.

A rigor gate

The service refuses to write a debt without a debtor and an amount, and never takes the LLM's word on balances: amounts in answers come from the database, not the model.

An audit trail

Every decision, including every refusal, is logged with the source message, confidence and reason. "Why did it do that?" always has an answer.

Engineered, not prompted

FastAPI, Pydantic AI and Postgres in a ports-and-adapters layout. The test suite runs fully offline with a fake LLM, so the logic around the model is pinned down.
